## Add a decision

1. Copy [adr/ADR-TEMPLATE.md](./adr/ADR-TEMPLATE.md) → `adr/ADR-NNNN-short-title.md` (e.g. `0001-database-choice.md`).
2. Fill Context, Decision, Options, Consequences; link FR-/NFR- IDs.
3. Set status; add a row to the table above linking to the file.
