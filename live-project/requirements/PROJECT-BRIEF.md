# Playo — Book-a-Ride (project brief)

**Track B.** Study plan → [study-plan/README.md](../../study-plan/README.md).

## Idea (one paragraph)

**Playo** books sports venues; **Book-a-Ride** adds transportation after venue booking so users can get to sessions (including early-morning/group). Phase 1 validates demand with a **manual/concierge pilot**; Phase 2 is an **automated single-rider MVP** if go/no-go criteria pass.

## Problem / opportunity

Users struggle to arrange transport to venues Playo already booked; Playo does not today help with the trip.

## Target users & stakeholders

Playo app users (players/organizers); ops/concierge for Phase 1 manual fulfillment; product/mentor review (_extend from BRD_).
